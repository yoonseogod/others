## 원형 (문화식 신원형)

- 몸판 폭 B/2+6, 가슴선 깊이 B/12+13.7, 앞중심 높이 (가슴선에서) B/5+8.3
- 등품 B/8+7.4, 앞품 B/8+6.2, BP = 앞품/2+0.7, 옆선 = (등품점 + 앞품점 − B/32)/2
- 뒷목너비 ◎ = B/24+3.4, 뒷목높이 ◎/3, 앞목너비 ◎−0.2, 앞목깊이 ◎+0.5
- 앞어깨 22° (앞품선 + 1.8) = ▲, 뒤어깨 18° = ▲ + (B/32−0.8)
- 가슴다트 (B/4−2.5)°, 어깨다트 B/32−0.8
- 소매: 산높이 = 평균 진동깊이 × 5/6, 앞 사선 = 앞AH, 뒤 사선 = 뒤AH + 1

## 자켓 전개

- **여유**: 진동 1cm 내림, 옆선 앞뒤 각 +0.5cm(가슴 +2cm), 목둘레는 옆목점에서 0.5cm 넓히고 앞중심에서 1cm 내림. 완성 허리 = W + 6.
- **허리 흡수 12cm**를 문화식 비율(a14 · b15 · c11 · d35 · e18 · f7 %)대로 배분했습니다: V솔기 e+f 3.00, 바깥 뒤솔기 d 4.20, 옆선 c 1.32, 앞 프린세스 a+b 3.48.
- **뒤요크**: 어깨다트를 닫아 요크 솔기로 옮겼습니다. 다트 끝점 D가 V솔기 시작점과 같은 위치입니다.
- **뒤판 3장**: 뒤중심판(골선, V형), 뒤중간판, 뒤옆판.
- **앞판**: 가슴다트를 진동 프린세스선으로 처리했습니다. 앞중심은 맞닿는 여밈(겹침 없음)이고 탭 5개로 잠급니다.
- **페플럼**: 솔기마다 2cm씩 플레어를 넣었습니다. 밑단은 CB −20, 옆선 −15cm(허리선 기준)이고, 앞중심은 둥근 모서리입니다.
- **소매**: 한 장 소매에 팔꿈치다트 1.5cm, 손목 쪽 2.5cm를 앞으로 이동, 소매부리 22cm, 뒤쪽 트임 8cm, 소매산 이즈 1.3cm(데님/트윌 기준).
- **스탠드칼라** 3.5cm(앞쪽 1cm 올림), **러플**은 3/4 원형 플라운스(폭 10cm), **벨트**는 91 × 3.5cm.
- **시접**: 전체 1cm, 골선은 0. 필요하면 재단할 때 밑단과 옆선 시접을 늘리세요.

## 검증 방식 (`verify.py`)

모든 세로 솔기는 직선 중심선을 기준으로 거울대칭 오프셋으로 만들었기 때문에 양쪽 길이가 수학적으로 같습니다. 프린세스선은 구간별(위→BP, BP→허리)로 장력을 수치 해석으로 풀어 0.1mm 이하로 일치시켰습니다. 검토는 10회로 나눠 진행합니다.

1. 원형 공식 재계산
2. 어깨·목둘레 (길이 + 교차각 90°/합 180°)
3. 진동둘레 교차 4곳(어깨, 요크, 프린세스, 옆선)의 각 합 180°, 변곡점 수, 최소 곡률반경
4. 세로 솔기 길이 (전체 / 허리노치 위·아래)
5. 밑단 교차각
6. 요크 솔기와 다트 처리
7. 소매산 이즈, 겨드랑점 직각, 산꼭지 수평, S곡선 변곡 1개
8. 소매 옆선, 팔꿈치다트, 소매부리 직각
9. 칼라, 러플, 벨트
10. 완성치수, 외곽선 폐합, 자기교차, 전 곡선 꺾임 검사, 4배 조밀 재샘플링 수렴

허용오차는 길이 0.1mm, 각 0.1°입니다.
